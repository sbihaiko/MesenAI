# The Python tools that ship in mesenai-tools-<version>.zip (scripts/release_macos.sh).
#
# One module per line, no path, comments and blank lines ignored. This is the
# transitive import closure of the tools named by docs/remastering-a-game.md and
# docs/hd-pack-authoring.md, plus the ones those tools shell out to. It is a
# hand-kept list rather than `scripts/*.py` because scripts/ also holds the test
# suites, the community-pack CI helpers and maintainer scripts that need `gh`,
# and none of those belong in a pack author's download.
#
# scripts/check_tools_zip_closure.py recomputes the closure and fails when this
# file and the closure disagree — so a tool that grows a new import cannot ship
# a zip that dies on ModuleNotFoundError.
#
# There is no entry-point list here to keep in sync: the guard reads the entry
# points out of the two guides (every `scripts/<name>.py` a guide tells the
# reader to run), so a guide line for a tool this file does not reach fails the
# build instead of shipping a "No such file" to the reader (#538). The one tool
# the guides do not name, and that no walk reaches, is listed as an extra entry
# point in the guard itself.
