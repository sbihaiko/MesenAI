# Double Dragon (1988) (Technos) - power-on to the place the selector names.
# ADR-0239 s1 rung 2: the place is chosen by the RAM byte $003D pinned for the
# run, so this entry script is the same for all four of them; what changes is
# the pin, and it lives in navigation.json's values[].value.
#
# The copyright sequence does not clear itself. Five runs with no input at all
# (12, 20, 30, 45 and 60 emulated seconds) end on the byte-identical frame -
# DOUBLE DRAGON / TRADEWEST / (c) 1988 TECHNOS JAPAN CORP. / LICENSED BY
# NINTENDO OF AMERICA INC. - all five at screenshot checksum 0xF3C0B496
# (probe/boot12..boot60).
#
# A START press does not clear it either. From that screen, START pressed at
# frame 400 and nothing else leaves the same picture at every end frame tried,
# 601 to 1803 (probe/t0400-*, probe/t0400s*, both p-t0400.txt), and the run
# never reaches a stage: the eight runs that saved a state (probe/t0400s10,
# s12, s14, s16, s18, s21, s24, s28) all read $0018/$0019 = 0000, where a stage
# would have put $C05C or one of its three siblings. Those
# end frames are not all byte-identical *to each other* - the picture pulses
# between checksums 0xE9AB185F and 0xF3C0B496, 8 277 of 61 440 pixels
# differing, every one of them a single palette step along the same ramp
# ((0,0,0) -> (108,6,0) on the red border, the white text one step brighter) -
# and the live timeline of that same probe shows both renderings before AND
# after the press (probe/live-t0400-frames, frames 108-375 and 413-2704), so
# the pulse is free-running and is not something START starts. probe/t0400-21
# is byte-identical to boot60, 0 of 61 440 pixels.
#
# SELECT is the press that clears it. Alone it brings up the title's MODE A/B
# menu - `MODE A 1PLAYER`, `MODE A 2PLAYER`, `MODE B 1PLAYER`,
# `MODE B 2PLAYER`, with a green heart at the head of the selected row
# (probe/selonly-frames/579d6a5eaa5f_244.png, probe/rw-in/selonly-180.txt).
# Measured at SELECT-at frames 5, 10, 20, 30, 40, 50, 55, 60, 80, 100, 110,
# 120, 130, 140, 150, 160, 170 and 180 - every one of them reaches a stage
# (probe/rw-sel: all 18 end states read $0018/$0019 = 5C/C0, the City Slum
# level-data pointer). START then begins the game.
#
# The lead-in is measured here and not copied from another set. The ROM's
# library folder ships a by-hand play script,
# "Double Dragon (1988) (Technos).play.txt", whose own first four steps are
# `180f -` / `12f S` / `30f -` / `12f T` - the same Select-then-Start path.
# This entry waits 60 frames before its SELECT where that script waits 180,
# which is 55 frames of margin on frame 5, the earliest SELECT measured to
# work. The frames after START belong to the run: with this entry the game
# first acts on the pinned byte at frame 104, 2 frames after the START press
# begins (frame 102), and $0018/$0019 holds the selected stage's pointer by
# frame 106, 2 frames after that - see the frame-accurate window in
# runs/f1418/doubledragon/RESULT.md and probe/nw*-*.
60f -
12f S
30f -
12f T
60f -
