# F12.19 — flicker-tolerant pose tracks (ADR-0226), validation (2026-09-23)

Slice F12.19 of `docs/roadmap/PRD-mesence-enhancement-ecosystem.md` implements
ADR-0226: `LinkPoseTracks` (`Core/NES/HdPacks/SpriteGrouping.cpp`) keeps a
cluster with no partner in the next retained frame as a pending end for
`kPoseTrackMaxGap = 1` frame, bridges it in a second nearest-first pass after
the adjacent-frame pass, and only across a skipped frame with
`RepeatCount <= kPoseTrackGapMaxRepeats = 2`. The skipped frame's
`RepeatCount` is added to the run it interrupts. This log records the
before/after on the bounded input the PRD row names.

## Unit tests (stop condition 1)

`make core-unit-tests`: 1007/1007. New cases (ADR-0226 §4, extending
ADR-0179 §6):

- a six-phase run drawn on every other retained frame is **one** track, a
  period-6 cycle of 3 turns, every phase `hold` 8 (drawn 4 times in 8
  frames), and the pose's own `hold` counts only drawn-frame links;
- one skipped frame of `RepeatCount` 1 or 2 is bridged and counted in the
  run's `Held`; two consecutive skipped frames, or one of `RepeatCount` 3,
  split the track;
- two figures where one flickers do not swap tracks across the gap: a
  geometry where the pending end is nearer (9 px) than the adjacent-frame
  partner (11 px). A mutation that runs the pending pass first makes this
  case fail with 3 tracks, so the test reads the pass order.

`TestTwoIdenticalRunsAreOneSequence` (ADR-0179 §6) separated its two passes
by one empty frame, which ADR-0226 now bridges; the fixture uses two empty
frames, keeping what it tests (two identical non-looping runs are one
sequence).

## Reproduction

```bash
  input=scripts/stages/contra/mint-stage1.txt save-state=<dir>/stage1.mss
MESEN_OAM_STREAM_DUMP=<dir>/full/oam.txt MESEN_POSE_TRACK_DUMP=<dir>/full/tracks.txt \
  headless_record <dir>/full/Contra.nes 61 <dir>/full/rec bootstrap hdpack-off \
  input=scripts/stages/contra/stage1-probe.txt state=<dir>/stage1.mss
```

Single-frame tracks are the lines of `tracks.txt` holding one
`frame:pose:1` run; cycles are read from
`<dir>/full/Contra/auto/textures/sheets/poses.json`.
